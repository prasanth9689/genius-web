# Contributing

Thanks for contributing to Genius Jobs.

1. Use a current Node.js LTS release and run `npm install`.
2. Keep changes focused and preserve the demo-only privacy boundaries.
3. Use fictional employers and listings; do not imply that demo applications reach real companies.
4. Run `npm test`, `npm run lint`, and `npm run build` before opening a pull request.
5. Include a short description of the behavior changed and any manual responsive/accessibility checks.

Please do not commit secrets, real candidate information, or uploaded resume files.
